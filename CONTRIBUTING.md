# Contributing to DeepResearch_CreateAgent

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository.
2. Create a new branch:

```bash
git checkout -b feature/my-feature
```

3. Install dependencies:

```bash
uv sync
```

4. Run tests:

```bash
pytest
```

5. Make your changes.

6. Commit your changes:

```bash
git commit -m "Add my feature"
```

7. Push to your fork and open a Pull Request.

## Code Style

* Follow PEP 8 guidelines.
* Prefer type hints.
* Keep functions small and focused.
* Add tests where appropriate.

## Reporting Issues

* Use the bug report template for bugs.
* Use the feature request template for enhancements.
* Use the question template for usage-related questions.

## Pull Requests

Please keep pull requests small and focused. Large PRs are harder to review and may take longer to merge.

Thank you for helping improve DeepResearch_CreateAgent!
